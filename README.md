# 🎟️ QR Ticket Application

QR Ticket Application is a full-stack ticket management system built with Spring Boot (backend) and React.js (frontend). The system generates unique QR-code-based tickets for users and allows event staff or administrators to verify tickets through scanning.

## 🚀 Tech Stack

- **Backend**: Java, Spring Boot, Spring MVC, Spring Data JPA, REST APIs
- **Frontend**: React.js, HTML, CSS, Bootstrap, Axios
- **Database**: MySQL
- **QR Integration**: QR Code generation & scanning libraries
- **Build Tool**: Maven
- **IDE**: Spring Tool Suite

## 🔧 Features

- 🎫 Online ticket booking system  
- 🔳 Unique QR code generated for every ticket  
- 📥 Downloadable digital ticket  
- 📱 QR code scanning & verification module  
- 👤 Admin dashboard for ticket management  
- 🔐 Secure ticket validation to prevent duplication  
- 🔎 REST APIs connecting React frontend with Spring Boot backend  
- 🎨 Responsive UI using React & Bootstrap  

### Installation  Prerequisites

- Java 17+
- Node.js & npm
- Maven
- MySQL
- Spring Tool Suite
